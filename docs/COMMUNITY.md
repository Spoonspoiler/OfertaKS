# Community

Community features are local data structures and reasoning helpers for now. A server is not implemented yet.

Current foundations:

- merchant price observations
- quality observations
- origin observations
- observation freshness
- quality aggregation with recency weighting
- origin provenance summaries

Community data must be shown with age, confidence, confirmation count, and provenance. Do not present user observations as equivalent to verified store labels or official data.

Future server responsibilities:

- shared merchants
- observation sync
- confirmations
- reports/moderation state
- conflict handling
- minimal privacy-conscious identity
